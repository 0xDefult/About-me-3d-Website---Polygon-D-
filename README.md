A fully interactive, scroll-driven 3D portfolio website built for the Polygon YSWS workshop.

This project explores procedural geometry, custom textures, and dynamic lighting on the web without relying on heavy frameworks or external assets.

🚀 Live Demo

https://3d-0xdefault.netlify.app/

🛠️ Tech Stack

This project strictly adheres to the vanilla web requirements:

HTML5: Semantic structure.

Vanilla CSS: Custom Glassmorphism UI and responsive layout (No Tailwind/Bootstrap).

Three.js: 3D rendering engine, mathematical procedural generation, and animation loops.

Vanilla JavaScript: Scroll event handling and DOM manipulation.
